COMMON QUESTIONS

FREQUENTLY ASKED QUESTIONS

Everything you need to know about course requirements, compatibility, and device setups.

Do I need to own a physical Elgato Stream Deck XL hardware device to take this course? ▾

Yes and No, physical hardware is not mandatory! You can follow all modules using Stream Deck Mobile on an iPhone, iPad, or Android phone/tablet with only 6 buttons - purchase a monthly, yearly, or lifetime subscription to unlock all 64 buttons . The Stream Deck desktop software is completely free to download from Elgato's website. You can design, organize, configure multi actions, and master all software features before investing in physical hardware.

Does this course cover both macOS and Windows operating systems? ▾

Yes and No We DO NOT provide side-by-side instructions for macOS and Windows. We cover the Desktop and Mobile software for Mac and iOS which works similarly to Windows and Android. Even though the video tutorials are recorded on a Mac, it is transferrable knowledge to Windows and Android environments. See Elgato support for specific details

What if I own a Stream Deck MK.2 (15 keys) or Stream Deck Mini (6 keys)? ▾

All concepts taught in this course—Smart Profiles, Multi Actions, Folders, Pages, Stream Deck Store plugins, and Wave Link—apply identically across all Stream Deck models. The course uses the Stream Deck XL (32 keys) as the primary canvas because it represents the flagship capability, and we show you how to scale and paginate the exact same layouts down to 15-key and 6-key decks.

How does Stream Deck Mobile pair with the desktop computer? ▾

Stream Deck Mobile pairs securely over your local Wi-Fi network. In Module 4, we walk you step-by-step through generating an encrypted pairing QR code inside the Stream Deck desktop software, scanning it with your phone or tablet camera, and optimizing network subnet settings for instant sub-millisecond response times.

How long do I have access to the course videos and downloads? ▾

You receive lifetime access to all course modules, downloadable icon packs, profile templates, and updates. Whenever Elgato releases major updates to the desktop software or mobile apps, we add new bonus lessons at no extra cost.

Will I receive a student certificate upon completing the course? ▾

Yes! Students who complete all 8 modules and submit the Capstone Certification Project in Module 8 receive an official verified Stream Deck Production Specialist Certificate to add to their portfolio and LinkedIn profile.
